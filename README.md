# Sales Data Analysis (SQL)

This project contains SQL scripts for analyzing sales performance over time using MySQL. The analysis includes:

- Monthly aggregation of order volume and revenue
- Running total of monthly revenue
- Month-over-month revenue growth trends

The data is stored in a table named `online_sales` within the `sales_db` database. Queries use Common Table Expressions (CTEs) and window functions for efficient time-series analysis.

Designed for use with MySQL Workbench or any MySQL-compatible environment.
